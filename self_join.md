## ASSIGNMENT ON SELF JOIN

1. WAQTD NAME OF THE EMPLOYEE AND HIS MANAGER'S NAME IF EMPLOYEE IS WORKING AS CLERK.
```SQL
-- USING ANSI SYNTAX
SELECT E1.ENAME "EMPLOYEE NAME", E2.ENAME "MANAGER NAME"
FROM EMP E1 JOIN EMP E2 ON E1.MGR = E2.EMPNO
WHERE E1.JOB = 'CLERK';

-- USING ORACLE SYNTAX
SELECT E1.ENAME "EMPLOYEE NAME", E2.NAME "MANAGER NAME"
FROM EMP E1, EMP E2 
WHERE E1.MGR = E2.EMPNO
AND E1.JOB = 'CLERK';

-- OUTPUT
EMPLOYEE N MANAGER NA
---------- ----------
JAMES      BLAKE
MILLER     CLARK
ADAMS      SCOTT
SMITH      FORD
```
